# Artes dos interiores da Ordem

Produção em 18/10/2026 com a ferramenta integrada `image_gen`, usando a fachada existente apenas como referência de estilo. Geração de peças novas, sem alteração dos personagens ou da fachada. Alpha preservado; as peças são consumidas por `scripts/city/convent_scenery.gd`.

Arquivos finais no repositório:

- [Arco do claustro](../assets/art/order/cloister-arch-v1.png).
- [Abside da capela](../assets/art/order/chapel-apse-v1.png).

## Prompt final — arco

```text
Use case: stylized-concept. Asset type: one reusable 2D game architectural sprite, a single cloister arcade bay. Reference image role: style and Portuguese Gothic architecture only. Generate a NEW isolated pale limestone pointed Gothic arch on two slender square pillars with carved capitals and worn plinths, a short horizontal stone lintel/parapet across the top. Fully open transparent arch opening, no wall filling the opening. Camera: elevated oblique three-quarter orthographic, looking slightly down, same painterly realism, warm cream stone, moss and warm sunlight as reference. Vertical columns, almost frontal broad face, subtly visible right thickness. Entire object visible with generous transparent margins. One arch only, no ground plane, no roof, no characters, no scenery, no text, no labels, no background, genuine transparent alpha. Crisp illustrated production sprite, harmonious with existing Mar de Jade convent facade.
```

## Prompt final — capela

```text
Use case: stylized-concept. Asset type: a single 2D RPG chapel apse backdrop sprite for a walkable room. NEW artwork matching style of reference Portuguese convent, elevated three-quarter orthographic viewpoint. Isolated cutaway shallow semicircular Gothic limestone apse with three narrow pointed stained-glass windows, warm cream stone and ochre plaster, central very modest stone altar with white cloth, red Order of Christ cross (red cross with smaller white cross within) mounted above altar, two brass candle stands, terracotta pot. Include the back wall and short side returns only, all foreground completely open, floor only a narrow strip under altar. No roof, no front wall, no nave, no seats, no people. Wide composition, complete object visible and generous transparent margin. Warm soft sunlight from upper left, hand-painted detailed game illustration with crisp materials and edges, restrained Portuguese late medieval style. Genuine transparent alpha outside the stonework, NO opaque gradient, NO colored backdrop, no text, no label, no watermark.
```
